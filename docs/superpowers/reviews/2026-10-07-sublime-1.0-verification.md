## Rulings I made

1. Validation exécutée dans GitHub Actions faute de PHP/Composer local ; coût : vérification distante et retours plus lents.
2. Matrice PHP et ordre des contrôles CI avancés à la première étape ; coût : infrastructure modifiée plus tôt, aucun contrôle final retiré.
3. Attente historique de l’apostrophe corrigée en &apos; pour ENT_HTML5 ; coût : représentation exacte différente de &#039; pour les consommateurs.
4. Texte capturé conservé brut en interne, échappé à la sortie ; coût : représentation interne modifiée, couverte par les tests de copies/rendu.
5. Clés du flux rendues séquentielles dès l’étape des enfants pour éviter la perte de morceaux ; coût : clés de générateur auparavant non documentées modifiées.
6. Attributs capturés à la construction, booléens HTML limités aux bool réels ; coût : valeurs comme disabled: 'false' désormais rejetées.
7. Noms d’attributs normalisés en minuscules ; coût : casse originale non conservée, contrat limité au mode HTML.
8. Contrôles de préfixe d’URL étendus aux espaces/contrôles ASCII internes ; coût : rejet conservateur de certaines URL inhabituelles, pas un assainissement général.
9. Callbacks nullable TagFactory acceptés ; types larges/unions, références et signatures variadiques rejetés ; coût : adaptation de ces anciens callbacks.
10. Validation Composer stricte ajoutée et PSR-4 runtime retiré, définitions chargées par files ; coût : métadonnées internes changées, noms publics préservés.
11. Installation documentée sur la branche et 1.0 annoncée non publiée ; coût : clonage nécessaire jusqu’à une publication séparément décidée.
12. Environnement local déconnecté à l’étape 6 : fin via API GitHub/Actions et relecture des sources distantes ; coût : instantané local obsolète, branche distante faisant foi.
13. Modèle de relecture et guide de fin récupérés depuis le dépôt public superpowers après l’indisponibilité du chemin local ; coût : source distante consultée, sans exécution des scripts locaux.
14. Premier essai de relecture interrompu sans retour exploitable ; une relecture de récupération est demandée sur la même version, sans deuxième avis de fond. Coût : délai supplémentaire ; seule la relecture achevée fera foi.
15. Les deux demandes de relecture indépendante n’ont produit aucun retour exploitable ; relecture finale par l’auteur via les sources GitHub. Coût : absence d’un regard indépendant avant intégration/publication, explicitement signalée.
16. Itérateurs infinis exclus car le contrat exige des itérateurs finis ; coût : l’appelant doit garantir la terminaison.
17. Assainissement général et conformité HTML complète exclus conformément au périmètre documenté ; coût : l’appelant applique les politiques contextuelles nécessaires.
18. Branche conservée sans fusion/tag/publication conformément au périmètre 1.0 candidate ; coût : intégration et distribution restent des étapes séparées.
